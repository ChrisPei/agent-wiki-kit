# Source Evidence and Provenance

Add captured evidence as a new artifact by default and register it in [`../sources.md`](../sources.md). Source history must remain understandable, but files are not universally immutable: an intentional correction, new version, relocation, redaction, or removal is allowed when the prior meaning is preserved or explained, affected links and conclusions are repaired, and the reason is recorded. Routine summarization must never silently rewrite evidence to fit a later conclusion.
